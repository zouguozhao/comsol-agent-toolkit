# 按目标制定最小可验证方案

本页为结合 LV2024、LIU2022 与既有热源笔记形成的建议，不是任一论文的原始算法。
文献及页码见[索引](index.md)；具体公式见[核查页](formula-audit.md)。

## 先选需要回答的问题

| 目标 | 最小路线 | 何时增加复杂度 | 验证对象 |
|---|---|---|---|
| 熔深、熔宽、热循环 | 三维移动等效热源＋瞬态传热＋合适的潜热处理 | 对流明显改变熔池形状时增加流动 | 功率积分、金相截面、测点热循环 |
| 熔池流速、温度均匀性、焊速影响 | 传热＋层流＋焓-多孔介质；按条件考虑浮力和 Marangoni 力 | 匙孔、自由表面运动或孔隙是目标时，再引入气液界面和蒸发/反冲机制 | 液态区流动、熔池轮廓、质量/能量收支、时空收敛 |
| 残余应力、翘曲、装夹影响 | 已校准温度历程→温度相关弹塑性结构→冷却与卸载 | 接触超声导致塑性、冲击或屈曲时增加对应非线性 | 残余应力路径、位移轮廓、卸夹顺序 |
| 晶粒或孔隙 | 先完成对应热流/界面模型 | 另需组织演化或缺陷形成模型及数据 | 实测组织或孔隙；热源图不能代替这些结果 |

COMSOL 可承接传热、流动及结构路线；Fluent 适合热流和 VOF 路线，结构应力需额外结构求解器或映射流程。具体接口、版本与许可证在实施时核实。

## 超声分成两个问题

**熔池内的平均输运作用**：需要输入位置、传播方向、耦合效率、工件内振幅或声强、衰减依据。
若目标为平均温度/流动，可评估声学场与时间平均体力的耦合。两篇文献没有提供可直接迁移到任意铝合金的完整声流标定。

**工具头作用于固体的振动或接触作用**：需要频率、工件侧位移/力、接触面积、预紧力、位置、拖尾距离和启停历史。
小振幅弹性响应可先做频域分析；若要预测永久塑性和残余应力，需要相应接触、塑性及卸载模型。
LIU2022 的底部拖尾装置不能直接等同于顶部声流体积力，也不能仅凭发生器功率确定工件载荷。

比较机制时分别建立基准、热场变化、机械载荷变化及组合工况；保持每一组对比中其余输入一致。
若分别用“无超声/有超声”的实测轮廓拟合热源，应称为已知轮廓下的条件分析。

## 开始建模所需数据

| 数据 | 用途与缺失时处理 |
|---|---|
| 材料牌号、状态；热物性、潜热、固液相线 | 明确来源及有效温区；钢材和泛称铝合金的数据不能直接变为 6061-T6 参数 |
| 板厚、接头、间隙、坐标与对称面 | 决定吸收域、半模型功率和边界；薄板屈曲需检查对称条件是否抑制变形模式 |
| 激光功率、波形、波长、光斑半径定义、速度、偏置 | 先确定局部源强和线能量，再校准有效吸收率及深度分布 |
| 夹具、支撑、散热、保护气、环境与释放时刻 | 分别定义热接触和机械约束；“忽略夹具对流”不等于忽略接触导热 |
| 超声频率、工件载荷及空间作用方式 | 区分位移峰值/RMS、声压、声强与电功率；未知耦合量先做有依据的敏感性分析 |
| 金相、测点温度、流动观测、位移或应力 | 把校准数据与独立验证数据分开；无数据时报告数值一致性和条件趋势 |

实际案例以用户参数与 `caseDict` 为准。上述缺口只在会阻塞所选路线时请求补充，不能通过抄论文表格补齐。

## 建模与验证顺序

1. **无超声基线**：按已知光斑定义建立守恒热源；校准熔深/熔宽与热循环，并保留独立测量点。
2. **按目标增加物理**：流动路线定义固液相变、阻尼及表面力；结构路线传递完整温度历程，并定义温度相关屈服/硬化与应力参考状态。
3. **加超声并做对照**：先核验载荷幅值和输入能量，再比较所需指标。机械作用研究需包含卸载后的状态。
4. **收敛与守恒**：检查每项面/体热源积分、热损失、潜热与储能；VOF 另查金属质量和界面分辨率。分别细化网格、移动热源步长及声学/接触时间步。
5. **扫描与评价**：扫描速度时列出 $P/v$ 或 $\eta P/v$，明确研究固定功率还是固定线能量；围绕候选区间细化。按熔深、缺陷、应力或变形目标评优，而非按云图外观。

数值实现中的 VOF 金属体积分数与固液相变液相分数是两个变量；不要混用。
焓法、等效热容法与额外潜热源不能重复计入同一潜热。
平面对称半模型保留局部源强，居中且完整截获时总功率约为全模型一半；进出边缘按实际截获功率核对。

## 时间尺度与结果口径

移动热源可用 $v\Delta t\le h_{\min}/2$ 作为初始步长建议，再做敏感性验证；这不是通用充分条件。
显式解析超声时可从每周期至少 20 个时间点开始检查，并继续细化；频域或平均模型需另说明近似依据。
VOF 还要满足对流、界面和表面张力的时间步约束。

残余应力应在声明的冷却及卸载状态评价。装夹下瞬时应力、卸夹后的残余应力与振动周期内应力幅值分别报告。
LIU2022 的全局等效应力峰值降低约 0.82%，变形差约 0.1 mm；提出改善方案时必须同时报告效果幅度、位置及数值/测量不确定性。

## Codex 输出方案的建议骨架

目标与已知输入 → 选用路线及文献依据 → 待补参数及用途 → 基准和对比工况 → 校准/验证指标 → 适用范围与不能支持的结论。
