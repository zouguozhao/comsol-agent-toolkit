# 激光与超声焊接：快速知识索引

## 从目标进入

| 用户要回答的问题 | 先读 | 重点限制 |
|---|---|---|
| 铝合金熔深、熔宽、温度和焊速趋势 | [方案选择](model-selection.md)中的热/流路线；[LV2024](lv-2024-fluent.md) | 原文参数存在冲突，20 mm/s 不是通用最优值 |
| 面源与体源怎么组合、怎么保证输入功率 | [复合高斯热源](../laser-composite-gaussian.md) | 必须明确吸收率、份额、半径和实际支撑域 |
| 已有金相轮廓，想估计温度、应力和变形 | [LIU2022](liu-2022-ultrasound-stress.md)；[方案选择](model-selection.md)中的热力路线 | 轮廓是校准输入，另用热循环、位移和应力验证 |
| 超声到底通过声流还是接触振动起作用 | [方案选择](model-selection.md)中的超声分支 | 熔池流动与固体塑性松弛需要不同模型 |
| 要把论文方程写进 COMSOL/Fluent | [公式核查](formula-audit.md) | 先修正量纲、符号、截断和时间尺度问题 |

## 两篇文献各取什么

| ID | 文献与对象 | 可学习内容 | 证据边界 |
|---|---|---|---|
| LV2024 | 吕成，2024；船用铝合金，Fluent | 能量—流动—相变—自由表面的模块组织；固定其他量扫描焊速 | 适合学习框架；缺少实验对照、完整求解设置和一致的激光参数 |
| LIU2022 | Liu 等，2022；0.6 mm SUS301L，底部拖尾超声 | 实测焊缝轮廓约束热源；温度到弹塑性结构的顺序耦合；多种测量交叉验证 | 有实测对照，但印刷公式有错误；不能直接移植钢材参数或宣称普遍降应力 |

## 最短阅读路径

1. 读[方案选择](model-selection.md)，确定目标和所需物理场。
2. 只读选中路线对应的文献笔记。每篇笔记给出原文页码、适用条件和数据缺口。
3. 需要编码时查[公式核查](formula-audit.md)；调用 COMSOL 时再查[操控指南](../control-guide.md)。

原文结果、独立核查和工程建议在各页分开标注。所有论文示例均不作为新案例的默认参数。

## 为什么沿用现有私有仓库

两篇文献与既有复合高斯热源及 COMSOL 工具共用材料、热源、超声和验证语境。
把领域知识放在本子目录可集中检索；Fluent 方法以物理模型描述，与 COMSOL 执行接口分开。
当知识扩展到多个无关领域，或需要不同访问权限、维护者和发布周期时，再考虑独立仓库。

GitHub 保存与版本管理知识。Codex 在可访问的工作区读取本仓库 `AGENTS.md`，
或按用户给出的链接读取本索引后使用这些内容；上传本身不会自动更新已安装的 Skill 副本。
