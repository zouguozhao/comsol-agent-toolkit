# 激光焊接复合高斯热源

用途：用面高斯描述表面吸收、体高斯描述深部等效沉积，供热传递与熔池流动模型复用。先保证积分功率守恒，再标定熔池轮廓；该热源本身不预测真实匙孔或晶粒。

## 可直接复用的公式

约定 $x$ 为焊接方向、$z$ 向上，深度从工件上表面向内为正：

$$r^2=(x-x_0-vt)^2+(y-y_0)^2,\qquad d=z_{\mathrm{top}}-z$$

| 参数 | 含义与约束 |
|---|---|
| $P(t)$、$\eta$ | 入射激光功率 W、有效吸收率 $0\le\eta\le1$ |
| $f_s$ | 面源功率份额 $0\le f_s\le1$；体源份额为 $1-f_s$ |
| $r_s,r_v,H$ | 面源半径、体源半径、实际沉积深度，均为正长度 |
| $a_s$ | 面源高斯形状系数，取2或3并固定半径约定 |
| $b$ | 深度衰减系数 $0\le b\le1$；0为均匀沉积，1为底端衰减至零 |

面源施加于上表面，单位为 W/m²：

$$q_s=\frac{a_sf_s\eta P(t)}{\pi r_s^2}\exp\left(-\frac{a_sr^2}{r_s^2}\right)$$

体源施加于 $0\le d\le H$ 的材料域，域外取零，单位为 W/m³：

$$q_v=\frac{6(1-f_s)\eta P(t)}{\pi r_v^2H(2-b)}\left(1-\frac{bd}{H}\right)\exp\left(-\frac{3r^2}{r_v^2}\right)$$

完整横向平面和完整沉积深度上的功率应满足：

$$\int q_s\,dA=f_s\eta P(t),\qquad\int q_v\,dV=(1-f_s)\eta P(t)$$

## COMSOL 表达式

在组件的“变量”中定义下列空间和时间表达式。长度与功率参数携带单位；eta、fs、asurf、b和g_t无量纲。连续恒功率时g_t=1，启停或渐增时令其为相应时间包络。

```text
r2 = (x-x0-v_weld*t)^2+(y-y0)^2
depth = z_top-z
Pabs = eta*P_laser*g_t
q_surface = asurf*fs*Pabs/(pi*rs^2)*exp(-asurf*r2/rs^2)
Q_volume = if((depth>=0)*(depth<=H),6*(1-fs)*Pabs/(pi*rv^2*H*(2-b))*(1-b*depth/H)*exp(-3*r2/rv^2),0[W/m^3])
```

“热通量”边界填q_surface，“热源”域节点填Q_volume。检查边界法向约定，使q_surface表示向内加热。已有体源占全部吸收功率时，先重新分配功率，再添加面源。

## 五个易错点

1. **深度与量纲**：Guo等式(10)的印刷形式按 $Q_v[\mathrm W]$、$H[\mathrm m]$ 得到 W/m²。上面的体源是以H为实际深度重新归一化的形式，不是作者代码的复原。若改用 $H/b$ 作为实际深度，必须更换归一化；两种约定不能混用。
2. **形状系数与吸收率**：$a_s$在面源积分中抵消。$a_s=2$对应 $1/e^2$ 半径，$a_s=3$对应 $e^{-3}$ 半径；$a_s$与$r_s$仅通过 $a_s/r_s^2$ 起作用，不应同时自由拟合。$r_v$内约含95.02%的横向功率，径向截断须另计尾部。
3. **热源形态**：固定$r_v$的公式不具有随深度收缩的高斯半径；亮斑收缩不等于几何锥体。需要锥形时显式定义 $R(d)$并重新归一化。源强图不能直接当作温度场或熔池边界。
4. **半模型与截面**：居中对称半模型保留完整模型的局部源强，在热源充分位于板内时积分约为 $\eta P(t)/2$。进出边缘、有限尺寸和时间包络按实际截获功率核验。二维截面须定义出平面厚度或单位长度功率，不能只删除一个坐标项。
5. **材料迁移与标定**：固定半径约定，用无超声基线标定 $\eta,f_s,H,r_v,b$，结合轮廓、熔深、顶宽或底宽及热循环约束参数；再固定热源比较超声工况。钛合金标定值不能直接用于铝合金，无实验数据时仅作敏感性分析。

## 最小核验

仅作数学自检的示例：$P=1500\ \mathrm W$、$\eta=0.7$、$f_s=0.5$、$a_s=3$、$r_s=r_v=0.5\ \mathrm{mm}$、$H=1.5\ \mathrm{mm}$、$b=1$。

| 应得到的量 | 数值 |
|---|---:|
| 面源积分 / 体源积分 / 总功率 | 525 W / 525 W / 1050 W |
| 面源峰值 | 2005.35 W/mm² |
| 体源峰值 | 2673.80 W/mm³ |

已完成解析与独立数值积分核验，$b=0,0.25,0.5,0.75,1$时体源积分均守恒；用m或mm计算得到相同功率。这不代表有限元网格、时间步或实验验证通过。实际算例还需检查两项功率积分、整体能量收支、网格和时间步敏感性。
